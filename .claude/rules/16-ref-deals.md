- `api/dealsApi.ts` (both roles, `DealRef {role, id}` → `/brand|/influencer/deals/{id}`, `utils/dealQuery`): infinite `getDeals` (`DealListArgs`, `status[]`), `getDeal` → `DealDetail {deal, funding}` (brand `meta.funding` while `awaiting_payment`), `getDealTimeline` / `getDealContract` (tag `DealHistory`). Screens call `useDealAction(ref, { idempotent })` → `run(path, {body, method})` → `DealActionOutcome` (conflict → server-message toast + key reset; in-flight tap shares the pending call; `isRunning`). Non-deal answers (rating, retention, dispute open/evidence, multipart `shipment/issue`) get their own mutations that invalidate `{Deal, id}`.
