# 16 — Ref: Deals core

Phase refs (Read when touching that phase, even from `DealDetailView` / `useDealDetail`): `16b` respond + shipping (P4, P5) · `16c` drafts + publish (P6, P7) · `16d` changes + disputes + retention (P8, P9) · `16e` discovery (Home, Explore, Shortlist, price lock) · `16f` finance.

- Deal types `types/deal.ts` (`Deal`, `DealItem`, `DealDraft`, `DealPublication`, `DealTimelineRow`, `Labeled<K>` = server `{key|null, label}`, epoch-ms `Timestamp`). Maps `constants/dealStatus.ts` (tone / outcome / phase, `DEAL_PHASES` + `DEAL_PHASE_LABEL`, `DEAL_STATUS_ACTIONS`, `DEAL_ITEM_ACTIONS`, `DEAL_DRAFT_REVIEW_TONE`), icons `constants/statusIcons.ts`.
- Wire shapes `types/dealDto.ts` (snake_case, enum keys `string`, `*_usd` strings, ISO times). Mappers `utils/dealMappers.ts` (`mapDeal`, `mapDealTimelineRow`, `mapDealDraft`, `mapDealPublication`, `mapDealContract`, `mapDealDisputeDetail`, `mapDealRetentionCase`, `mapDealRatingEntry`, `mapDealFile`, `mapBrandActiveDeal`, `mapDealStrikes`): money via `parseUsd`, unknown enum → `null`, server `influencer` → role `creator`; malformed money / required time throws (never show a wrong amount). Import directly in `api/`, not via barrel.
- `api/dealsApi.ts` (both roles, `DealRef {role, id}` → `/brand|/influencer/deals/{id}`, `utils/dealQuery`): infinite `getDeals` (`DealListArgs`, `status[]`), `getDeal` → `DealDetail {deal, funding}` (brand `meta.funding` while `awaiting_payment`), `getDealTimeline` / `getDealContract` (tag `DealHistory`). Tags `Deal` (id) · `DealList` (LIST) · `DealHistory` (id). `runDealAction` = every route answering the full deal (`DealActionPath` union): success upserts `getDeal` from `data` + invalidates `dealChangedTags(id)` (lists, history, BrandHome, wallet/escrow); `409|403 deal_*` (`isDealConflictError`) refetches the deal. Screens call `useDealAction(ref, { idempotent })` → `run(path, {body, method})` → `DealActionOutcome` (conflict → server-message toast + key reset; in-flight tap shares the pending call; `isRunning`). Non-deal answers (rating, retention, dispute open/evidence, multipart `shipment/issue`) get their own mutations that invalidate `{Deal, id}`.
- `getDealActions(deal, role, now)` / `getDealItemActions` / `buildDealProgress({status, stage, hasShipping, frozenFrom})` (`utils/`, tested). Stopped deals → no progress (screen shows outcome).
- Parts: `DealStatusPill` (`Labeled` status, server label) `DealProgress` (phases) `DealCard` (`deal` + `role`, `onPress(id)`) `CreatorCard` (Explore / Shortlist row: 88pt photo beside details, monogram on `brand.soft`; ❤️ `ShortlistHeart` beside the card via `onToggleShortlist`; teal handshake disc bottom-end via `onRequestOffer` → `useCreatorCardActions.requestOffer` → `OfferBuilder {slug}`; `ShortlistHeart onMedia` = frosted disc over photos) `DraftReviewCard` (`round` + server `review`).
